• Financial News Web Application
This repository contains a Financial News web application developed using HTML, CSS, and JavaScript. The website fetches real-time financial news articles from external APIs and dynamically displays them in a structured and user-friendly format.

• About This Project
The Financial News application is designed to provide users with the latest financial and market-related news from various sources.

The project demonstrates:
-> Integration of third-party News APIs
-> Fetching and handling JSON data
-> Dynamic content rendering using JavaScript
-> Responsive web design using HTML and CSS
-> API-based real-time data updates

• Tech Stack
lang: HTML, CSS & Js
APIs: News API
